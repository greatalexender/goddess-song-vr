# src/interaction/ — 手势与注视互动

- 目标设备形态：全程双手（手部追踪）+ 注视，手柄可选；坐姿静止体验。
- 已定手势（设计稿）：摊手唤光（第 2 段）、合掌归静（第 5 段）；
  每段至多一处大手势，其余靠注视与停留推进，不做复杂手势语法。
- 本目录负责：手势识别系统、注视停留（gaze dwell）触发、无手柄教学
  （开场 30 秒内让体验者自己学会第一个手势，不用文字教程）。
- 组件声明（如手势触发标记）写在无 system 依赖的模块里，
  并登记到 `src/components.ts`。

第四阶段实现注记：手势识别没有单独建 system，而是并入
`src/spaces/arc-system.ts` 的段落状态机（手势的语义就是「完成
本段」，与段落推进同生命周期，拆开反而要跨系统传状态）。识别
走手部关节矩阵（IWSDK visualAdapters 的 jointTransforms 乘
grip 空间世界矩阵），约 100 ms 采样一次做阈值判定：掌心法线、
手指伸直数、双掌心距、轨迹画圆、胸口锚点接近、手速。注视停留
用头部射线到标记环心的垂距判定，捏合确认用
`input.xr.getSelectState`。若后续手势种类变多，再从 arc-system
里拆出独立的识别模块到本目录。
