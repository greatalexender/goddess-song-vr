# src/spaces/ — 五个空间（五段弧）

对应设计稿《女神之歌_VR体验设计稿_v0.1》的五段弧 → 五空间映射：

| 段 | 空间 | 说明 |
|---|---|---|
| 1 | 呼唤 | 入园，灯未亮，歌声自远处来 |
| 2 | 回应 | 灯亮起，第一处手势互动（摊手唤光） |
| 3 | 交融 | 花园全貌展开，歌与空间交融 |
| 4 | 内在之光 | 光收束向内，空间转静 |
| 5 | 归于宁静 | 合掌归静，灯与歌同熄/同留 |

每个空间一个模块（建议 `space-1-call.ts` … 命名自定），负责该段的
场景资产登记、段内系统与进出过渡；段落切换的编排系统放本目录根部。
空间专属的 `*.scene-asset.ts` 仍放 `src/scene-assets/`，在本目录只写逻辑。
骨架阶段本目录为空，第一个空间开工时从这里长。

第四阶段已落地（2026-10-26）：

- `spaces.ts`：五空间组织表 + `applySpaceLampAudioLevel` 灯光驱动
  钩子（签名不变，驱动方见下）。
- `arc-components.ts`：`ArcDirector` / `LandingMarker` 组件声明
  （登记在 `src/components.ts`）。
- `arc-system.ts`：段落状态机——入口 → 五空间按弧推进；每段一个
  大手势（摊手 / 合掌 / 画圆交叠 / 点胸 / 放下静止）完成后点亮通往
  下一空间的落点标记，注视停留 1.2 s 或捏合确认后淡出换位；
  第 5 段完成后开自由回访（归静处一排小光点）。手势识别不到时
  捏合长按 2 秒兜底。本系统同时是灯光钩子的驱动方：当前段落灯
  以正弦 0.85–1.15 呼吸（测试曲线），微光内纹 48 秒一圈慢转。
